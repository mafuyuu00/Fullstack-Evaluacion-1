## Nota importante sobre las rutas

El catálogo de productos y el carrito ahora utilizan la ruta organizada `assets/img/productos/<filename>`. Las demás carpetas están listas para imágenes de marca, banners, equipo, íconos y pagos. Algunos comentarios HTML antiguos todavía muestran las rutas planas originales como documentación y se pueden actualizar cuando se agreguen esos archivos restantes.
